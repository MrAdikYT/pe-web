Náklady (lekce 3)

nákladová funkceCN = FN + vn·q, vn = VN / q
dvě obdobívn = ΔCN / Δq (min a max objem), FN = CN − vn·q
nejmenší čtvercevn = (n·Σq·CN − Σq·ΣCN) / (n·Σq² − (Σq)²), FN = (ΣCN − vn·Σq) / n

Bod zvratu a rentabilita (lekce 4)

ziskZ = p·q − FN − vn·q = (p − vn)·q − FN
bod zvratuBZ = FN / (p − vn) [ks], BZ·p [Kč]
různorodá produkceBZ = FN / (1 − VN/T) [Kč]
objem pro ziskq = (FN + Z) / (p − vn)
limit FNFN = (p − vn)·q − Z
limit vnvn = p − (FN + Z) / q
minimální cenap = vn + (FN + Z) / q
kritické využitíVkrit = BZ / kapacita
bezpečnostní maržeMS = (q − BZ) / q
příspěvek na úhraduPÚ = T − VN = FN + Z, PT = (p − vn) / p
rentabilita nákladůr = Z / CN; při daném r: FN = p·q/(1 + r) − vn·q
rentabilita tržeb, VK, kapitáluZ / T, Z / VK, Z / celkový kapitál
nákladovostn = CN / výnosy; Q = FN / (n − vn) [Kč]
nevyužité / uspořené FNFN·(1 − k) / FN·(k − 1), k = qs / qp
