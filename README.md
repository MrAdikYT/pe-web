# Podniková ekonomika: příprava na zápočet

Statický web k zápočtové písemce z předmětu Podniková ekonomika (VŠB-TUO, EKF). Písemka má 30 bodů, k zápočtu je potřeba 16, a obsahuje jen výpočetní příklady z cvičení.

## Obsah

- **Lekce** (`lessons/`): rozvaha, výkaz zisku a ztráty, náklady a nákladová funkce, bod zvratu a rentabilita, výrobní kapacita, oběžný majetek. Každá má kvíz a generátor náhodných příkladů s kontrolou a postupem.
- **Cvičná písemka** (`lessons/0007-cvicna-pisemka.html`): 6 příkladů × 5 bodů, pokaždé jiná.
- **Tahák** (`reference/vzorce.html`): všechny vzorce na jednom místě.

Začni na `index.html`. Web je čisté HTML, CSS a JavaScript bez sestavování, takže běží přímo na GitHub Pages.
